# Дизайн-система Grid Studio

Каталог: `design-system/index.html`. Источник — существующие компоненты редактора, без нового визуального направления.

## Источники

- `typography.css` — четыре общие роли текста, одинаковые на всех ширинах экрана.
- `tokens.css` — общие цвета, шрифты, размеры, отступы и геометрия.
- `buttons.css` — единая стеклянная кнопка: обычная и основная фиолетовая.
- `fields.css` — общая типографика полей и размер иконки глазика.
- `sliders.css` — компактный слайдер с подписью и редактируемым значением.
- `checkboxes.css` — чекбокс с градиентом без декоративного контура.
- `panels.css` — плоские поверхности редактора.
- `empty-state.css` — размещение кнопки загрузки по центру холста.

`npm run build:design-system` обновляет веб-редактор и автономный `Grid Studio.html`. Общая сборка запускает этот шаг последним. CSS внутри assets и автономного HTML — результат сборки, не место для ручных правок. Старые скрипты стилей читают эти же файлы.

## Использование

В существующем React runtime кнопки создаются компонентом `ri` (LiquidButton), с `className:"liquid-button-primary"` для основного действия. Он создаёт обязательные слои lens, surface и content. Не заменять его обычной кнопкой с отдельно нарисованным градиентом. Вне React использовать разметку из каталога.

Слайдеры — `Ge` (строка настройки), `cg` (Radix Slider), `GridParameterValue` (числовое значение). Использовать существующую механику клавиатуры, ограничений и ввода. Каталог монтирует эти же компоненты через `catalog.js`; отдельной реализации слайдера нет.

Числовые поля — `GridDimensionInput`, цвет и прозрачность — `GridLineControl`, градиенты — `GradientPicker`. Для новых настроек использовать эти компоненты и существующие классы. Иконки — существующий набор stroke SVG; глазик 18 px, остальные кнопочные иконки 16 px. Размер иконки меняется независимо от кликабельной области.

## Зафиксированные решения

- Подписи слайдеров: 10 px, как «Цвет линий». Высота строки: 34 px.
- Слайдеры имеют общие минимальную и максимальную позиции; колонки 63 px / свободное место / 48 px, промежутки 16 px.
- В узкой панели проверить самую длинную подпись, оба конца шкалы и значение с единицей измерения.
- Отступ перед чекбоксом 6 px. У чекбокса нет декоративной обводки; клавиатурный focus ring сохраняется.
- HEX и число колонок используют одинаковые размер и насыщенность, включая адаптивный режим.
- Основные действия загрузки и экспорта имеют одинаковый материал, форму и состояния.

## Границы

Система подключена к основному редактору и его автономной версии. Галерея и учебные прототипы — отдельные интерфейсы: их не мигрировать автоматически и не считать источником новых вариантов компонентов редактора.

При отсутствии нужного компонента сначала проверить каталог и runtime. Новый вариант добавлять в общий компонент и каталог; не добавлять локальный CSS-дубль. Проверять desktop с панелью 272 px, узкий экран, hover, focus, disabled, минимум/максимум слайдера. Не менять согласованный дизайн при техническом рефакторинге.

## Типографика

Использовать только четыре роли, определённые в `typography.css`:

| Роль | Шрифт | Размер / интерлиньяж | Вес |
| --- | --- | --- | --- |
| Заголовок | Avito Sans Display | 14 / 20 px | 400 |
| Подпись | Avito Sans Text | 10 / 15 px | 400 |
| Значение | Avito Sans Text Mono | 10 / 15 px | 500 |
| Кнопка | Avito Sans Text | 12 / 16 px | 400 |

Цвет — отдельный вариант акцента. На узком экране не менять кегль: адаптировать область нажатия. Документация каталога может использовать более крупный текст для чтения. Образцы каталога используют те же классы ролей, что и редактор.

## Дополнительные поверхности

Выбор эффекта, направление лент, названия градиентов и варианты в меню используют роль «Кнопка». Заголовок палитры — «Заголовок», RGB/HEX — «Значение», сообщения загрузки и ошибок — «Подпись». Временная шкала видео — отдельный медиаконтрол в `media.css`; время использует роль «Значение». Значки закрытия и отметки выбора не являются текстовыми стилями.

Аудит 15.10.2026: проверены четыре режима эффектов на ширинах 1280 и 640 px, всплывающие градиенты и поля цвета, пустое состояние. Нативный select может возвращать `line-height: normal` из-за отрисовки браузером; шрифт и кегль соответствуют роли. Видеоконтролы проверены по исходному коду и тестам, без воспроизведения файла в этой проверке. Старые декларации в исходном статическом CSS сохранены как базовый слой; актуальные правила дизайн-системы применяются последними.

## Живой каталог

`catalog.js` импортирует основной runtime и монтирует настоящие Slider, ParameterValue, DimensionInput, LineControl, GradientPicker и LiquidButton. Адаптер `scripts/build-component-catalog.mjs` открывает этот API и предотвращает запуск редактора, если нет его корневого узла. Он входит в общую сборку. После изменения runtime отдельно выполнить `node scripts/build-component-catalog.mjs`.

Загрузка, пауза, экспорт и выбор эффекта в примерах управляют настоящим редактором во встроенном iframe. Изолированные примеры слайдеров, цветов и градиентов имеют собственные значения, но тот же код поведения. Иконки — визуальные образцы, а не отдельные действия.

## Shared gallery components

The impression and image-upload dialogs use modal.css and LiquidButton. Both gallery headings preserve the upload dialog’s 24 px Avito Sans Display style. Padding: 24 px desktop, 20 px mobile; form gap: 16 px; input height: 40/44 px. Native dialog preserves Escape and focus. The catalog form does not submit data.

bubbles.css provides decorative blue word bubbles matching gallery image glow. They are not buttons.

The build generates gallery-prototype/design-system.css from shared sources. Do not edit it manually. These two gallery components are migrated at the user's request; other gallery surfaces retain their existing design.
