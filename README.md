# Grid Studio

Веб-редактор изображений с сеткой, эффектами и экспортом PNG.

Для запуска в браузере откройте опубликованную страницу GitHub Pages.
Для работы офлайн скачайте `Grid Studio.html` и откройте его в Safari 17+ или актуальной Opera / Chrome. Node и сервер не нужны.

Тактильный отклик трекпада macOS недоступен обычной веб-странице. Визуальные состояния сильного нажатия поддерживаются там, где браузер передаёт эти события.

Шрифты интерфейса: Avito Sans Text — подписи и кнопки, Avito Sans Text Mono — числовые значения и коды цветов, Avito Sans Display — заголовки. Файлы находятся в `fonts/` и встроены в автономный `Grid Studio.html`. Для обновления подключения выполнить `node scripts/build-fonts.mjs`; основная сборка также обновляет шрифты.

## Action и палитра Конфа’26

Блок выбора палитры убран из интерфейса. Базовые цвета: фон `#07080B`, свет `#FFFFFF`; Action сохраняет спектральные засветы.

Action использует выбранный вариант F3: радиальное растяжение деталей с разносом RGB-каналов, мягкий bloom, широкие направленные цветные засветы и красно-оранжевое тонирование теней. Центр изображения и светлые участки защищены от избыточного искажения и тонирования. Чёрный фон не становится источником света.

Настройки по умолчанию: размер 24, интенсивность 80%, шлейф 16. Размер управляет цветовым разносом и шириной засветов, шлейф — растяжением деталей, интенсивность — силой обработки. «Размер чёткой зоны» (0–100%, по умолчанию 16%) меняет радиус области вокруг центра с минимальным спектральным искажением. Переход к искажённым краям плавный. Сброс возвращает 16%. Готовое изображение рассчитывается при изменении настроек и затем используется повторно. Рендер заменяет содержимое только ячеек Action. Экспорт 1080×1080 масштабирует тот же результат с рабочего холста 600×600.


Редактируемый модуль: `source/clean-effect.ts`. Скрипт `scripts/build-clean-style.mjs` обновляет модуль, палитры и настройки в существующем статическом runtime и автономном `Grid Studio.html`, сохраняя мобильную вёрстку и экспорт. Для повторной сборки установить dev-зависимости из `package.json` и выполнить `npm run build`. Если esbuild уже установлен в другом каталоге, можно передать его абсолютный путь через `GRID_ESBUILD_PATH`.


## На телефонах

Канвас подстраивается под экран, кнопки располагаются под изображением, настройки — ниже в общей прокрутке. Цвета применяются сразу. Экспорт сохраняет размер 1080×1080 px и логотип.

## Dot Matrix

Отдельный эффект: белые сплошные круги на чистом чёрном фоне. Шаг по умолчанию 6 px (диапазон 4–60 px), единый для всего рабочего холста, включая стыки ячеек. Диаметр достигает 80% шага. Светлота рассчитывается через взвешенное среднеквадратичное RGB, чтобы насыщенные цветные лепестки лучше сохраняли видимость. После сглаживания анализируется всё изображение; почти чёрный и прозрачный фон не участвует в статистике. Нижняя опорная точка берётся из 8-го перцентиля, верхняя — из 96-го с запасом для светов. Минимальная ширина диапазона защищает от усиления шума. Кривая диаметра имеет степень 0.70. Покрытие окрестности ослабляет узкие структуры с минимальным множителем 0.65. Профиль общий для всех ячеек редактора. Необязательный аргумент `profile` позволяет зафиксировать диапазон для будущей обработки видео; импорт видео по-прежнему отсутствует. Усреднение по окрестности подавляет текстуру и тонкие структуры; тени плавно растворяются. Палитра не меняет чёрный фон и белые точки. Декоративная сетка редактора управляется отдельно.

Модуль: `source/dot-matrix.js`; обновление веб-версии и автономного HTML: `node scripts/build-dot-matrix.mjs` (также включено в общую сборку). Импорт видео пока не поддерживается; координаты точек детерминированы и не зависят от времени.

Для сохранения стеблей смешиваются крупная и малая области измерения светлоты, а глубокие тени плавно поднимаются до применения кривой диаметра. Почти чёрный фон отсеивается отдельным плавным порогом.

## Цветные точки

В Dot Matrix добавлена «Палитра точек»: Оранжевый и синий (по умолчанию), Спектр, Бирюза и фиолетовый, Монохром. Доступен выбор только готовых палитр; полоска под списком показывает выбранный градиент. Оранжевый и синий использует #FF6E14 → #FFFFFF → #34A4FA → #3E6BFF. Градиент растянут по области объекта; фон остаётся чёрным, диаметр точек определяется адаптивной светлотой. Палитра применяется ко всем ячейкам Dot Matrix и сохраняется в PNG. Переключатель «Анимация градиента» включает плавную деформацию крупных размытых цветовых областей с циклом 20 секунд: области растягиваются и смешиваются, как текучий mesh-градиент. Геометрия точек остаётся неизменной. Монохром и системная настройка уменьшения движения отключают движение. PNG сохраняет текущий кадр.

## Ribbons

Выбор края кистью вместо деформации половины кадра. Без выделения изображение не меняется. Проведите по внешним краям лепестков; розовая маска показывает источник лент. Ластик удаляет часть выбора, «Очистить выбор» удаляет всё, «Показывать выделение» независимо скрывает розовую маску, сохраняя ленты и возможность рисовать. Кисть доступна всё время, пока выбран Ribbons. Кнопка «Ластик» показывает включение выделенным состоянием без смены надписи. Кисть поддерживает мышь, перо и касание; размер 6–80 px. Результат обновляется после завершения штриха.

Независимые настройки: «Ширина захвата» 1–40 px (по умолчанию 24), «Длина лент» 0–100% ширины холста, «Изгиб» 0–100%, направление влево/вправо. Захват ограничен выбранными кистью пикселями. Каждый связный участок маски формирует отдельную поверхность. Её граница сглаживается совместно по высоте; провалы исходной текстуры не превращаются в длинные щели. Цвет ленты берётся из выбранной поверхности с локальным подавлением примеси фона, без размытия основного изображения. Выбранная поверхность непрерывно вытягивается от внутренней границы маски к краю: деформация нарастает плавно, изгиб создаёт широкие складки и выпрямляется вдали. Невыбранные пиксели объекта остаются без изменений; центр цветка нужно оставлять вне выделения. Фон оценивается по краям кадра; лучше всего подходят однотонные фоны, автоматическая защита не является семантическим выделением на сложной фотографии.

Маска сбрасывается при замене изображения, смене масштаба и общем сбросе. Рисование отключает случайный цикл. Маска — отдельный слой интерфейса и не входит в PNG. Эффект рассчитывается на всём холсте до разбиения на ячейки. Модуль `source/ribbon-stretch.js`, сборка `node scripts/build-ribbon-stretch.mjs` включена в `npm run build`. Проверки: `node tests/ribbon-stretch.mjs`.

## Цвет Letters

В Letters доступен тот же список палитр, что в Dot Matrix, в том же порядке: Спектр, Оранжевый и синий, Бирюза и фиолетовый, Монохром. Оба списка используют общий каталог. По умолчанию — Оранжевый и синий; выбор Letters независим от Dot Matrix. Градиент статичный, общий для всего изображения, без перезапуска в каждой ячейке; яркость букв сохраняет светотень исходника. Настройки применяются к ячейкам Letters и PNG. Общий сброс возвращает палитру по умолчанию. Модуль `source/letters-color.js`, сборка `scripts/build-letters-color.mjs` входит в общую сборку; проверка `node tests/letters-color.mjs`.

## Случайный цикл

Стили выбираются с мягким штрафом за совпадение с соседними клетками по стороне и за избыток одного эффекта в кадре. Повторы остаются возможны. Начальное заполнение идёт в перемешанном порядке; последующие замены также учитывают соседей и не повторяют текущий стиль клетки.

Ленты: геометрия складки теперь меняет ширину поверхности по длине (сужение и расширение) и использует наклон выбранного участка для направления поворота. «Изгиб» управляет этой деформацией. Субпиксельная интерполяция заменяет округление и усреднение пяти строк, сохраняя тонкие линии; цвет шлейфа слегка насыщеннее. К краю холста шлейф плавно растворяется в исходном фоне. Невыбранные пиксели объекта сохраняются. Ленты рассчитываются отдельно в 1200×1200 из оригинала с учётом масштаба и яркости. Предпросмотр уменьшается до 600×600, экспорт PNG 1080×1080 берёт слой лент непосредственно из расчёта 1200×1200. Остальные эффекты сохраняют прежний путь экспорта. Результат лент кэшируется до изменения параметров, маски или исходника.

Сетка при запуске и сбросе — 6 × 6. Смена эффекта использует перекрёстное затухание 0,7 секунды; в случайном цикле снимок накладывается только на изменяемую клетку. Остальные анимированные клетки продолжают движение.

Граница маски имеет внутренний плавный переход, не расширяющий выделение. Затухание шлейфа зависит от локального контраста: тонкие яркие линии сохраняются дальше, широкие участки растворяются быстрее.

## Взаимодействие с Letters

Буквы реагируют на курсор и касание, расходятся в стороны и плавно возвращаются. Нажатие усиливает отклонение. В панели Letters можно выключить взаимодействие, изменить радиус (30–200 px) и силу (0–100%). При видимой сетке движение ограничено ячейками Letters. При скрытой сетке буквы свободно пересекают внутренние границы соседних ячеек Letters без швов; области других эффектов в смешанной сетке защищены. «Стоп кадр» фиксирует положение для PNG. При системной настройке уменьшения движения эффект остаётся статичным. На сенсорном экране жест внутри холста управляет буквами; прокрутка доступна вне холста или после выключения взаимодействия.

Модуль: `source/letters-interaction.js`; сборка: `node scripts/build-letters-interaction.mjs` (также входит в `npm run build`). Проверка: `node tests/letters-interaction.mjs`.

## Видео

Кнопка загрузки принимает изображения и видео. Видео обрабатывается локально, без отправки файла на сервер. MP4/H.264 и WebM подходят в зависимости от кодеков браузера. После загрузки доступны воспроизведение и стоп-кадр под холстом, а также ползунок позиции с таймингом справа в панели видео. Пробел фиксирует и видео, и движение эффектов; PNG сохраняет текущий обработанный кадр с логотипом. Предпросмотр беззвучный.

Для видео основная кнопка под холстом — «Экспорт видео»; для изображения — «Скачать PNG». Отдельный кадр видео можно сохранить кнопкой «Сохранить PNG» под холстом рядом с «Экспорт видео».

«Экспорт видео» записывает один проход с начала ролика в реальном времени, с эффектами, сеткой согласно её видимости и логотипом. Исходный звук включается в запись, если он есть. Выходной размер — 1080×1080. Браузер выбирает поддерживаемый MP4 или WebM. «Завершить и сохранить» сохраняет записанный фрагмент; в конце ролика запись завершается автоматически. После записи доступна ссылка повторного скачивания. Во время записи держите вкладку открытой и активной. Частота кадров зависит от сложности эффекта и мощности устройства; запись запрашивает до 30 fps. Для видео Ribbons обрабатывает рабочие 600×600, а для изображений сохраняется расчёт повышенного разрешения.

Модуль `source/video.js`, сборка `scripts/build-video.mjs` (входит в `npm run build`). Проверки: `node tests/video.mjs`. Для браузерной проверки: `GRID_PLAYWRIGHT_PATH=/path/to/playwright node tests/video-browser.mjs /path/to/test.mp4`. Браузерный тест использует локальный Chrome и сохраняет временные результаты в `/tmp`.

## Адаптация к исходнику

Letters и Dot Matrix используют общую оценку светлоты полного кадра: диапазон определяется по перцентилям, насыщенные цвета измеряются через взвешенное RMS RGB. Для Letters фиксированное отсечение 25% заменено плавным адаптивным порогом, а яркость символов нормализуется к диапазону исходника. Чёрный и почти чёрный шум не поднимаются. Палитры остаются выбранными пользователем. Профиль видео плавно обновляется с постоянной времени 0.35 с; при обратной перемотке или скачке от 0.7 с сбрасывается. Адаптация работает в предпросмотре, на паузе и при экспорте через общий рендер. Action и Ribbons не перекрашиваются. Проверки: `node tests/adaptive-tone.mjs`.


### Облегчённый предпросмотр видео

Во время воспроизведения эффекты рассчитываются на холсте 300×300, максимум 12 раз в секунду. После тяжёлого кадра интервал увеличивается до 2,5 длительности его расчёта, оставляя время интерфейсу и другим приложениям. При стоп-кадре, перемотке и сохранении PNG возвращается исходный рабочий размер 600×600. Экспорт видео также использует 600×600 без понижения предпросмотра и сохраняет файл 1080×1080. PNG и начало записи дожидаются подтверждения готовности полного кадра. Работа с изображениями остаётся на 600×600.

В скрытой вкладке предпросмотр и декодирование приостанавливаются; активная запись продолжается. Запись копирует холст только при появлении нового обработанного кадра. Размеры букв, координаты курсора и маска Ribbons учитывают масштаб предпросмотра. Кэш букв переиспользует холсты, а смещения букв сохраняются при смене разрешения.

Источники: `source/video-performance.js`, `source/video-render-loop.js`. Проверки политики качества: `node tests/video-performance.mjs`. В локальном тесте Chrome с Action на предоставленном ролике за 5 секунд TaskDuration снизился с 5,00 до 1,98 секунды; число считанных пикселей — с 25,92 до 7,65 млн. Это измерение нагрузки главного потока конкретного браузерного теста, а не гарантия частоты кадров на всех устройствах.
