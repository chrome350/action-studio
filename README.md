# Grid Studio

Веб-редактор изображений с сеткой, эффектами и экспортом PNG.

Для запуска в браузере откройте опубликованную страницу GitHub Pages.
Для работы офлайн скачайте `Grid Studio.html` и откройте его в Safari 17+ или актуальной Opera / Chrome. Node и сервер не нужны.

Тактильный отклик трекпада macOS недоступен обычной веб-странице. Визуальные состояния сильного нажатия поддерживаются там, где браузер передаёт эти события.

Шрифт Unbounded распространяется по лицензии SIL OFL: `fonts/Unbounded-OFL.txt`.
